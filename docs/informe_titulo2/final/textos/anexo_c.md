Todo el código, los datos de resultados y los documentos de trabajo están en el repositorio del proyecto: github.com/Vatelfil/slippage (rama `main`).

| Componente | Ubicación en el repositorio |
|---|---|
| Pipeline de datos, simuladores, entornos y agentes | `src/` |
| Scripts de entrenamiento, evaluación y análisis | `scripts/` |
| Cuadernos de Google Colab usados en las corridas | `notebooks/` |
| Resultados de las corridas (JSON y tablas) | `data/colab_resultados/` |
| Consolidación 3.2.2, comparación 3.2.3 y sensibilidad 3.2.4 | `data/analysis/3_2_2/`, `data/analysis/3_2_3/` y `data/analysis/3_2_4/` |
| Figuras y tablas de los capítulos 6, 7 y 8 | `data/analysis/cap6_MR/`, `data/analysis/capitulo7_BF/`, `data/analysis/cap7/` y `data/analysis/figuras_4_1_4/` |
| Pruebas automáticas | `tests/` |
| Documentos de trabajo por tarea | `docs/` |
| Generador de este informe | `docs/informe_titulo2/final/` |

Las cifras de cada capítulo indican el archivo de donde salen. Las pruebas automáticas verifican que las tablas y figuras coincidan con los datos consolidados.
